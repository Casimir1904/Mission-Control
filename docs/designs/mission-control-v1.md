## Vision

### 10x Check
The prototype was a task management tool that happened to manage agents. The 10x version is the **operating system for AI agent teams** — "Linear meets Datadog, purpose-built for AI agents."

Key elements:
- Real-time agent consciousness (live streams of agent thinking/doing/planning)
- Agent-to-agent coordination as a first-class primitive
- Institutional memory that compounds (every interaction builds organizational knowledge)
- One-click fleet deployment (agent team templates → any gateway)
- Cost/value attribution engine (token costs vs. task outcomes)

### Platonic Ideal
A spatial map of the organization — boards as clusters, agents as moving nodes, tasks as flowing particles. Zoom into a board → Kanban. Zoom into an agent → live thought process, memory, task history. Zoom out → the entire operation as a living system.

The feeling: "I can see everything my AI team is doing, and I trust it."

Qualities:
- Spatial awareness (always know where you are: org → group → board → agent → task)
- Progressive disclosure (simple for 3 agents, powerful for 200)
- Trust through transparency (every action auditable, every decision traceable)
- Alive, not static (real-time updates, live metrics, streaming activity)

## Accepted Scope (added to this plan)

### Core Platform (rebuilt from scratch)
- Multi-tenant organization management with member roles & RBAC
- Board groups and boards for hierarchical work organization
- Task management with dependencies, lifecycle states, recurrence
- Agent lifecycle management, health monitoring, heartbeats
- Gateway management with WebSocket communication
- Approval workflows with rubric scores, confidence levels, audit trails
- Activity timeline / audit log
- Skills marketplace for agent capabilities
- Custom fields for extensible metadata
- Tags system for categorization
- Chat interface for human-agent communication
- Webhook system for external integrations
- Dual authentication (local bearer token + Clerk JWT)
- API-first with OpenAPI documentation

### Expansion Features
1. Real-Time Operations Dashboard ("Mission Control Room")
2. Agent Memory Management UI (explorer, search, edit, timeline)
3. Smart Onboarding Wizard (5 questions → auto-configured board)
4. OpenTelemetry-Native Observability (traces, spans, cost tracking)
5. Agent-to-Agent Communication View (threads, delegation chains)
6. Cost & Value Attribution Engine (per-agent/task/board economics)
7. Notification System (in-app, configurable rules, daily digest, webhook-out)
8. Visual Topology / Relationship Map (interactive graph view)
9. Command Palette + Keyboard-First Navigation (Cmd+K, vim shortcuts)
10. Comprehensive Documentation Site (Astro/Docusaurus, API ref, guides)
11. Operations Calendar (month/week/day views, drag-to-reschedule, click-to-create, recurring task visualization)

## Key Decision: Starting from Scratch
The user explicitly chose to start from a clean codebase, not iterate on the prototype. The existing code serves as a learning resource and reference for data models, but the architecture, code organization, and implementation will be fresh.

## Competitive Context
- No open-source tool combines: agent lifecycle + task boards + approvals + team coordination + memory UI + gateway management + self-hosting
- Market is clustered around *building* agents; nobody owns *operating* them
- Mission Control occupies genuinely uncontested territory
- Key competitors analyzed: CrewAI, AutoGen, LangSmith, Langfuse, AgentOps, Dify, Flowise, n8n, OpenHands
